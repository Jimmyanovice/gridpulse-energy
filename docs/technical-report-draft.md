# GridPulse：面向新能源波动的净负荷预测与候选运行风险研判

## 摘要

GridPulse 是一个面向能源管理的可复现软件原型。项目使用 Open Power System Data（OPSD）公开的德国小时级负荷、光伏和风电数据，构造净负荷 `total_load - solar - wind`，并完成数据质量检查、因果一步超前预测、候选运行风险筛查和理论储能情景模拟。数据处理后保留 50,400 条小时记录，未发现重复时间戳或缺失时间间隔。冻结测试期中，Histogram Gradient Boosting 的 MAE 为 1,019.87 MW，优于随机森林的 1,126.88 MW。风险模块包含峰值负荷、光伏骤降和持续预测偏差三类候选信号；由于数据不含故障标签，项目仅进行确定性注入压力测试。储能模块在显式 SOC、功率、效率、应急储备和日内能量分摊假设下进行理论模拟，不构成节省、可靠性或部署结论。

## 1. 问题定义

新能源出力的波动会改变区域净负荷的水平、爬坡和峰值。项目定义目标变量为：

```text
net_load = total_load - solar_generation - wind_generation
```

系统输出包括：

1. 下一时刻净负荷的因果预测；
2. 面向峰值、光伏骤降和持续偏差的候选风险信号；
3. 带有约束说明的理论化储能建议。

当前版本是历史回测原型，不是实时调度系统、故障诊断系统或直接 24 小时预报系统。

### 1.1 赛题定位与应用闭环

本作品拟申报科技创新组，主攻“新能源消纳与并网智能调控”。应用对象是需要观察新能源波动、判断净负荷压力并安排人工复核的能源管理或运行分析人员。系统不直接向设备下发控制指令，而是把公开历史数据转换为可审计的下一小时预测、预测区间、候选风险和理论削峰情景。

应用方法分为四步：首先对负荷、光伏和风电进行统一时间标准、质量检查和净负荷计算；其次使用只读取预测时刻前一小时及更早信息的模型给出一步超前预测和经验区间；再次依据验证期冻结阈值生成峰值负荷、光伏骤降和持续偏差候选信号，并保留触发证据；最后以预测触发的 SOC 约束储能规则模拟削峰可能性，向人工复核提供容量和约束提示。

在当前公开数据边界内，应用效果表现为：选定模型测试 MAE 为 1,019.87 MW，相对季节性朴素基线改善 88.36%；五个扩展滚动窗口均优于基线；经验预测区间在冻结测试期覆盖率为 86.92%；风险规则能够在确定性注入压力测试中识别预设事件。上述结果证明的是数据链路、模型链路和规则链路可以运行并可复现，不是现场准确率或故障诊断准确率。

预期效益是把新能源波动下的“看不见的风险”转化为带证据的人工复核清单，并在储能尚未实际调度前比较容量、功率和备用假设对削峰结果的影响，从而降低方案评估和演示验证的门槛。真实节省、电网可靠性、碳排放和运行安全收益必须在获得实时量测、设备参数、价格规则和调度授权后另行验证，本报告不提前宣称这些收益。

## 2. 数据与质量

数据来自 OPSD Time Series 2020-10-06 公开发布，项目记录了下载地址、字段映射、DOI 和第三方声明。处理后数据覆盖 2015 至 2020 年，频率为 60 分钟。质量报告显示：

| 项目 | 结果 |
|---|---:|
| 有效小时记录 | 50,400 |
| 缺失时间戳 | 0 |
| 重复时间戳 | 0 |
| 净负荷公式最大误差 | 0 MW |
| 含缺失数值的行 | 105 |

缺失值没有被静默填补；模型特征构造后仅使用可用的历史信息，并明确排除不可用行。

## 3. 方法

### 3.1 特征与时间切分

模型使用小时、星期、月份的周期特征，净负荷 1/24/168 小时滞后和滚动统计，以及光伏、风电 1/24 小时滞后。所有观测特征均先移位，预测时刻只使用前一小时及更早信息。数据按时间顺序划分为训练、验证和冻结测试区间；验证集用于阈值与策略决策，测试集只用于最终报告。

### 3.2 模型比较

项目比较季节性朴素参考、随机森林和 Histogram Gradient Boosting。当前结果是一步超前因果回测。若要形成直接 24 小时预报，需要增加在发布时可获得的天气或新能源预测输入，并重新定义信息边界。

### 3.3 候选风险规则

风险阈值全部由验证期分位数校准：预测净负荷 95% 分位用于峰值风险，光伏小时变化 5% 分位用于骤降风险，绝对残差 97.5% 分位并持续 3 小时用于偏差风险。输出保留触发值、阈值和证据文本。风险事件不是已确认故障。

### 3.4 理论储能情景

储能模拟以一步预测触发削峰，初始 SOC 为容量的 50%，充放电效率各为 92%，最大放电功率为 2,500 MW，最大充电功率为 1,250 MW。常规峰值期间保留 30% 容量作为应急储备，并采用容量/24 小时的保守有效放电上限，避免一次高负荷日过早耗尽能量。充电阈值、极端阈值和风险阈值均来自验证期。

## 4. 结果

### 4.1 预测结果

| 模型 | 测试 MAE (MW) | 测试 RMSE (MW) |
|---|---:|---:|
| 季节性朴素 | 8,760.67 | 11,857.65 |
| 随机森林 | 1,126.88 | 1,501.19 |
| Histogram Gradient Boosting | 1,019.87 | 1,354.19 |

消融结果显示，去除新能源滞后后测试 MAE 增加 100.17 MW，去除滚动统计后增加 15.16 MW，仅保留日历特征时退化至 9,160.43 MW。这些结论只适用于当前数据和冻结测试区间，不能视为普适因果结论。

为检查季节稳定性，项目增加了 5 个固定起点的扩展窗口滚动回测，每个窗口评估连续 30 天。梯度提升模型在 5/5 个窗口中优于季节性朴素基线，MAE 均值为 837.30 MW，窗口间标准差为 174.41 MW。该结果增强了跨时间段的稳健性证据，但仍不是跨区域泛化证明。

项目还使用验证集绝对残差的 90% 分位数校准对称经验预测区间。梯度提升模型的区间半宽为 1,984.79 MW，验证期覆盖率为 89.99%，冻结测试期覆盖率为 86.92%。该区间是经验校准带，不是概率保证。

### 4.2 风险压力测试

测试期共有 1,023 行至少触发一类候选风险。由于没有真实故障标签，项目向测试副本注入确定性的 25 个三小时事件，峰值、光伏骤降和持续偏差规则均能识别对应注入点。该结果只验证规则机械响应，不代表真实故障检测准确率。

### 4.3 储能敏感性

| 容量 | 放电小时 | 受控 P95 (MW) | 全期最大值降幅 (MW) |
|---|---:|---:|---:|
| 10,000 MWh | 297 | 54,186.8 | 416.7 |
| 20,000 MWh | 300 | 54,185.0 | 833.3 |
| 30,000 MWh | 304 | 54,185.0 | 1,250.0 |

这些数值是理论策略输出，不等于实际成本、碳排或可靠性收益。

## 5. 系统实现与复现

数据、质量、EDA、基线、模型、风险和情景脚本位于 `scripts/`；核心实现位于 `src/`；交互演示由 `app.py` 提供。完整运行顺序见 `docs/reproducibility.md`。最终预检命令为：

```powershell
python scripts/final_preflight.py
```

截至当前版本，预检包含 pytest、核心输出文件、预测口径、储能敏感性和 PPT 结构回执检查，结果写入 `.codex-finalizer/gridpulse-final-preflight.json`。

## 6. 局限与后续工作

- 数据是单一区域的历史公开发布，不含真实故障标签；
- 当前预测为一步超前回测，不是直接 24 小时预测；
- 光伏骤降规则在回测中使用实际观测，生产版本需替换为实时量测或可用预测；
- 储能策略未建模网络约束、价格、退化、备用义务和调度授权；
- 仍需将本文导出为比赛要求的 PDF，完成人工匿名检查、PPT PDF 检查和 3–5 分钟演示视频。
