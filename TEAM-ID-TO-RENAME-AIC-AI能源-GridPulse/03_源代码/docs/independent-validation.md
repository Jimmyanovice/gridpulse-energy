# 2021 年独立时间留出验证

## 预先锁定的协议

本轮先创建 `outputs/validation/independent_2021_protocol.json`，记录冻结时间、六组配置、主次指标、重采样方法，以及模型、控制代码和校准文件的 SHA-256，随后才下载全年观测。现有模型不重训，区间、普通峰值门槛、充电门槛和 q99 释放阈值全部沿用原验证期结果。没有对新数据进行功率缩放或阈值搜索。

披露：协议前曾请求 2021-01-01 至 01-03 的短样本，核对 API 字段、单位和时间戳；展示过首行观测，未运行预测/调控、拟合参数或查看策略效果。因此不宣称全年每个观测都完全未见。另附排除这三日的 362 日敏感性，明确标为事后披露复核，不取代预先指定的全年主指标。

评估区间固定为 `[2021-01-01 00:00 UTC, 2022-01-01 00:00 UTC)`。2020-12-24 起的数据只提供历史特征暖机，2022-01-01 前六小时只提供年末完整预测窗口的目标记录，不计入评估指标。该时间段位于原 OPSD 数据覆盖结束之后，未参与模型训练、校准或此前峰值策略开发。这是同一国家的后续年份留出，具有不同数据提供方；不能称为跨国家验证或现场前瞻试验。

主指标是新动态组合相对原动态上界策略的**全年最高受控净负荷差值**。正值表示该年度出现改善，零或负值均如实保留。次指标覆盖 P95、所有季度、前 20 个实际高负荷小时、吞吐、转换损耗、软储备缺口、硬 SOC 下限和日末等式。主指标没有假设检验或总体极值置信区间。

## 数据、许可与时间口径

来源：Energy-Charts.info / Fraunhofer ISE 的 `/v2/public_power` API，德国 `country=de`。文档为 https://api.energy-charts.info/ ，接口模式为 https://api.energy-charts.info/openapi.json ，数据按接口声明采用 CC BY 4.0，归属 Energy-Charts.info。

| 源字段 | 本项目映射 | 处理 |
|---|---|---|
| `load` | `total_load_mw` | 每小时四个完整 15 分钟 MW 值取均值 |
| `solar` | `solar_generation_mw` | 同上 |
| `wind_onshore` + `wind_offshore` | `wind_generation_mw` | 分别聚合后相加 |
| 自行计算 | `net_load_mw` | 负荷减光伏减陆上与海上风电 |

API 的时间戳表示区间开始，原生时区 Europe/Berlin，统一转为 UTC 后聚合。因此夏令时转换不会产生重复 UTC 小时。重复时间戳直接拒绝；任一小时不足四个完整观测就保留 NaN，不填补。只评估六组策略共有的完整 UTC 日，并公布排除日。

行动时刻 `t` 控制 `[t,t+1h)` 的负荷。最新特征观测标记 `t-1h`，覆盖 `[t-1h,t)`，只在其结束 `t` 后视为可用。本次将原特征构建器的发布标签整体加一小时，使一小时模型对应“发布后第一小时结束的区间平均功率”，各时距仍共享同一发布时刻。假定小时结束即可获得量测，额外发布延迟未建模，需要用户核验。

原 OPSD 与 Energy-Charts 数据口径和历史修订可能不同。项目不将新提供方观测与旧数据直接拼接训练，也不按新负荷规模调整控制器。原始响应、提供方生成时间、下载时间、许可、原始及标准化数据哈希保留在本地；发布包附标准化数据和质量报告，原始大 JSON 可从记录的 URL 获取。最新历史版本无法恢复每个时刻当时实际可用的数据版本。

## 不确定性与适用范围

按 UTC 日保持 24 小时动作和负荷整体，使用配对循环移动区块重采样，同一批日期索引同时作用于新旧策略，避免破坏策略配对。主设置为 7 天区块、2,000 次、随机种子 20211009，报告平均日最高峰削减和 P95 削减的百分位 95% 区间。另报告 3 天、14 天区块敏感性。

区间只反映当前年份观测日和已冻结预测下的重采样变动，依赖局部平稳假设，不包含模型训练误差、数据口径差异、未出现极端事件或未来年份风险。全年最高峰作为已观测描述性指标单独报告，不将样本极值重采样解释为未来极值保证。季度和消融均是次要分析，不对多个指标挑选显著性结论。

容量 30 GWh、充放电各 1,250 MW、单向效率 0.92、硬下限 15%、每日日初日末 50% SOC 保持不变。独立 UTC 日、50% 上限和全天允许补电仍是仿真假设。软储备释放不代表满足合同备用义务。收益、电价、退化、网络、现场授权及跨区域泛化仍需要用户核验，参赛队应按赛事规则核查方法与材料披露。

## 完整结果与结论

六组均评估 365 个完整 UTC 日、8,760 小时，无排除日。原始最高净负荷为 70,449.90 MW，发生在 2021-11-10 16:00 UTC；新动态和新固定的受控最高点仍在该时刻，均为 69,199.90 MW。

| 冻结配置 | 最高净负荷 (MW) | P95 (MW) | 吞吐 (MWh) | 损耗 (MWh) |
|---|---:|---:|---:|---:|
| 原固定，上界目标 | 70,449.90 | 58,731.82 | 868,858.54 | 72,279.39 |
| 原动态，上界目标 | 70,449.90 | 58,962.80 | 803,647.83 | 66,854.59 |
| 动态，仅软储备释放 | 70,449.90 | 59,027.41 | 819,237.35 | 68,151.46 |
| 动态，仅点目标 | 70,062.83 | 58,858.94 | 1,305,791.79 | 108,627.39 |
| 新动态组合 | 69,199.90 | 59,035.77 | 1,396,437.01 | 116,168.07 |
| 新固定组合 | 69,199.90 | 58,661.79 | 1,657,314.84 | 137,870.21 |

主指标达到了预先定义的观测成功条件：新动态相对原动态全年最高点降低 1,250.00 MW（约 1.77%）。平均日最高点降低 237.39 MW，7 天配对区块的 95% 区间为 [184.73, 293.93] MW；3 天、14 天区块的对应区间为 [188.78, 289.94] 与 [176.45, 299.05] MW。该平均日指标的改善在这些重采样设置下保持一致，但不表示每天都改善。

全年 P95 则升高 72.97 MW。以“旧减新”为削减方向，P95 差为 -72.97 MW，7 天区块 95% 区间 [-359.59, 78.15] MW，覆盖 0，不能支持 P95 改善。3 天和 14 天区间也覆盖 0。吞吐增加 592,789.18 MWh，损耗增加 49,313.48 MWh，软储备目标缺口为 444 小时，包含主动释放；六组硬下限违规和最大日末误差均为 0。

| 季度 | 完整日 | 原动态最高点 (MW) | 新动态最高点 (MW) | 最高点削减，旧减新 (MW) | P95 削减，旧减新 (MW) |
|---|---:|---:|---:|---:|---:|
| Q1 | 90 | 69,421.55 | 68,270.03 | 1,151.53 | 18.35 |
| Q2 | 91 | 59,468.33 | 59,427.56 | 40.78 | 349.92 |
| Q3 | 92 | 61,629.32 | 61,859.50 | -230.18 | 326.71 |
| Q4 | 92 | 70,449.90 | 69,199.90 | 1,250.00 | 30.72 |

Q3 最高点变差 230.18 MW，需要明确保留。四个季度的 P95 都有所下降，全年 P95 仍上升：分位数不是线性平均量，全年必须直接按所有 8,760 小时计算，不能平均四个季度分位数或据此宣称矛盾。

按日最高点方向统计，新动态改善 132 日、持平 222 日、变差 11 日。排除 API 探测涉及的前三日后，362 日最高点削减仍为 1,250 MW，平均日削峰 237.30 MW，7 天区块 95% 区间 [183.84,290.45] MW；P95 升高 192.14 MW，其削减区间 [-364.13,80.90] MW 仍覆盖零。该披露敏感性见 `independent_2021_robustness.json`。

相对新固定组合，新动态的最高点相同、P95 高 373.98 MW，吞吐少 260,877.83 MWh、损耗少 21,702.14 MWh。仅点目标最高点比组合高 862.93 MW，但 P95 低 176.84 MW、吞吐也更少。主结果证明组合在该年极端峰值上的改进，不能证明动态储备本身全面优于固定储备，也不能据此取消点目标单独版本的价值。

前 20 个实际高负荷小时中，新动态改善 17 个，平均削减 936.49 MW；原动态改善 9 个、平均削减 227.20 MW。该集合用真实观测选取，只用于事后评价，不参与策略决策。冻结一小时模型的 MAE 为 982.65 MW，同期持平参考为 2,354.40 MW；冻结区间覆盖率为 88.03%，未达到名义 90%，不能视为概率保证。六个时距的完整预测指标均保留。

**当前可支持的结论：** 点预测目标与极端软储备释放的组合，在预先锁定的 2021 年同国后续历史留出仿真中，复现了全年极端最高峰和平均日最高峰的改善。旧测试仍属于探索性设计证据，2021 结果提供额外的时间泛化证据。P95 优势未复现，季度极值存在失败，削峰需要更高吞吐与损耗；动态和固定储备各有取舍。所有结论受数据版本、零额外发布延迟、储能与补电假设约束，现场可行性、可靠性、寿命和经济收益仍需要用户核验。

## 复现

本验证结果后的全局最优性审计另见 `docs/global-optimality.md`。2021 年物理功率下界为 69,199.90 MW，现有新动态及新固定均达到；仅能说明该有限模型的全年最高峰值最优，不能说明吞吐、P95 或未来在线策略最优。新增离线调度及精确有理数证书不更改本冻结协议，也不是新的独立验证。

首次运行必须在持有原冻结模型和校准工件的原开发仓库内，且尚未下载本验证数据：

```powershell
python scripts/run_independent_validation.py freeze
python scripts/run_independent_validation.py download
python scripts/run_independent_validation.py evaluate
python scripts/final_preflight.py
```

已附协议的发布包可直接运行 `download` / `evaluate`，不再次执行 `freeze`。冻结输入变化时脚本拒绝运行，避免无声重新训练后保留原预登记名义。公开 API 内容后续可能修订；哈希不一致的新下载应视为新数据版本并单独记录，不能假定精确复现原快照。
