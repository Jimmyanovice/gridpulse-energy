# 极端峰值响应：诊断与可复现改进

## 问题与信息边界

原动态每日恢复策略在测试期最高实际净负荷时刻（2019-11-20 16:00 UTC，69,256 MW）没有放电。当时电量为 15,000 MWh、动态软储备目标约 14,246.88 MWh。发布于前一小时的一小时点预测为 70,276.70 MW，已捕捉到高负荷。限制并非电池完全没有电量，而是软储备压缩可用能量，且不同预测时距的区间半宽使较远小时的上界更高。原最小最大上界目标将动作推迟。

该诊断来自已知测试结果。新方案的测试结论必须标为探索性，不能将验证期校准阈值等同于独立确认。

## 优化目标与储备释放

改进使用同一组直接 1--6 小时预测，分别改变两个机制：

1. 点预测规划：以 `P_h + c_h - d_h <= z` 替代目标中的 `U_h + c_h - d_h <= z`，仍最小化 `z + 0.001 * sum(c_h+d_h)`。区间上界继续用于动态储备和放电触发。此版本不再具有原上界最小最大目标的解释。
2. 极端负荷释放：阈值 `E` 为直接一小时模型验证期点预测的 99% 分位，约 63,183.08 MW。若当前发布窗口中 `max(P_h) >= E`，将该窗口可释放的软储备下限降至共同硬下限；否则继续使用原储备下限。没有用测试最高峰搜索阈值。

两种策略均保留 30 GWh 容量、1,250 MW 充放电上限、0.92 单向效率、4,500 MWh 硬下限和每日初末 15,000 MWh 等式。窗口在日末截断，日末可达下限也继续执行。恢复模式允许任意小时补电，并计入补电负荷、转换损耗和吞吐。求解仅读取发布预测、当前 SOC、已知日历与额定功率，不读取实际未来负荷。

## 对照协议

报告以下六种配置，避免把组合收益归因于单个机制：

| 配置 | 规划目标 | 普通储备 | 极端释放 |
|---|---|---|---|
| 原固定 | 区间上界 | 固定 30% | 无 |
| 原动态 | 区间上界 | 动态 | 无 |
| 动态，仅释放 | 区间上界 | 动态 | 有 |
| 动态，仅点目标 | 点预测 | 动态 | 无 |
| 新动态组合 | 点预测 | 动态 | 有 |
| 新固定组合 | 点预测 | 固定 30% | 有 |

每个时间分区内六组共享完整 UTC 日；验证期和测试期分开报告。测试原固定/原动态直接读取已交付的每日恢复轨迹，保持原证据不变。其余配置由同一模拟器生成。验证期模型不重训，使用原训练期模型输出。

主指标为整个比较期的最高受控净负荷，不能仅统计原最高峰所在小时，因为最高点可能转移。同步报告 P95、前 20 个实际高负荷小时的平均削减与改善数量、吞吐、损耗、硬下限违规、补电导致的负荷增加小时和最大日末误差。前 20 小时由实际值选取，仅用于事后评价，不参与决策。

## 当前复核结果

测试期六组均使用 417 日、10,008 小时。原动态最高受控净负荷为 69,256 MW，仅释放软储备降至 69,122.05 MW，仅点目标为 68,657.77 MW，组合为 68,610.15 MW。原最高峰小时组合放电 1,250 MW，但最高点转移至 2019-11-25 14:00 UTC，所以全期削峰为 645.85 MW。

| 测试配置 | 最高负荷 (MW) | P95 (MW) | 吞吐 (MWh) | 损耗 (MWh) |
|---|---:|---:|---:|---:|
| 原动态 | 69,256.00 | 54,030.65 | 350,858.30 | 29,187.52 |
| 新动态组合 | 68,610.15 | 53,860.55 | 651,031.03 | 54,158.56 |
| 新固定组合 | 68,610.15 | 53,829.99 | 851,572.50 | 70,841.39 |

新动态相对原动态 P95 低 170.10 MW，但吞吐多 300,172.74 MWh、损耗多 24,971.04 MWh。相对新固定组合，最高峰相同、P95 高 30.56 MW，吞吐少 200,541.46 MWh。仅点目标的 P95 还比动态组合低 21.02 MW。该结果支持不同目标的取舍，不能宣称组合或动态策略全面占优。

新动态在前 20 个实际高负荷小时改善 12 个，平均削减 509.03 MW。软目标未达 193 小时，包含主动释放的影响；共同硬下限违规和最大日末误差为 0。验证期六组均使用 208 个完整日、4,992 小时，两种组合最高峰同为 72,010.57 MW，较无控制的 72,655 MW 低 644.43 MW。验证与测试的全部消融、逐小时动作和软目标缺口保留在 JSON/CSV 中。

## 复现与审计

运行 `python scripts/run_peak_response.py`，输出 `outputs/scenarios/peak_response_metrics.json` 与 `peak_validation_*_timeseries.csv`、`peak_test_*_timeseries.csv`。完整前置流水线见 `docs/reproducibility.md`。`python scripts/final_preflight.py` 从 CSV 重算逐小时能量守恒、功率、每日初末电量以及各组时间点一致性。

## 适用限制

后续新增预先冻结的 2021 年时间留出验证，见 `docs/independent-validation.md`。新动态全年最高点下降 1,250 MW、平均日最高点下降 237.39 MW，但全年 P95 上升 72.97 MW、Q3 最高点变差 230.18 MW。该结果补充时间泛化证据，原测试的探索性标签仍保留；不能概括为所有指标或所有季节都改善。

- 验证期也用于区间和释放阈值校准，验证结果是内部诊断。
- 新设计发生在旧测试峰值已知后，测试结果是探索性复核。
- 软储备释放不等于满足真实备用义务；硬下限 15% 也是模型假设。
- 单区域、独立 UTC 日、50% SOC 上限、全天可补电等假设不代表现场网络可行性，需通过现场数据和设备条件验证。
- 尚未建模电价、退化、网络和调度授权，不能由削峰推出收益或可靠性承诺。
