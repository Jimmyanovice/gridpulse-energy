# GridPulse 有限实例全局最优性证书

本扩展是已知结果后的数学审计，不改变原冻结模型、控制器、阈值或 2021 年验证协议。证明对象是明确的数据、物理模型和目标，不能将“一个实例的峰值最优”扩大为“作品、算法或所有未来场景全局最优”。

| 2021 年，365 个完整 UTC 日 | 70,449.90 | 69,199.90 | 69,199.90 | 0.00 |
| 旧探索性测试，417 个完整 UTC 日 | 69,256.00 | 68,006.00 | 68,610.15 | 604.15 |

两组离线调度的峰值最优和随后最低吞吐均有精确有理数证书；现有 2021 年新动态轨迹的可行性、达到下界使用独立浮点残差核验，容差 0.00001 MW/MWh。新固定策略在原冻结评价中也达到同样峰值；不能把达到物理下界归因于动态储备的独有优势。

离线解利用所有真实负荷，且只追求全年最大值及其后的最低吞吐；不承担降低其余高峰、保持软储备或价格套利的任务。因此上表不是在线节省或部署收益，不能拿最低吞吐差额当作可实现收益。2021 年离线最低吞吐解 P95 高于现有新动态的 59,035.77 MW，已直接显示不同目标存在取舍。

## 2. 固定问题的定义

每小时 t 已知净负荷 L_t。变量为充电功率 c_t、放电功率 d_t、小时末能量 E_t 和全年最大净负荷 z。时间步长固定 1 小时，功率 MW 乘时间后为 MWh。单向效率 eta = 0.92，往返效率为 0.8464。

目标按优先级求解：第一阶段最小化 z；第二阶段固定 z = z*，最小化 T = sum(c_t + d_t)。这里不使用加权和 z + epsilon*T；任何非零权重都可能允许主目标变差，不是严格优先级。

物理约束：

```text
L_t + c_t - d_t <= z
0 <= c_t <= 1250; 0 <= d_t <= 1250
E_t = E_(t-1) + eta*c_t - d_t/eta
4500 <= E_t <= 15000 MWh
每个 UTC 日 E_start = E_end = 15000 MWh
不同时充放电，即 c_t*d_t = 0
```

设备容量为 30,000 MWh；15,000 MWh 是原每日恢复实验的操作上限，不能改成设备容量后沿用本证书。各日为独立完整的 24 小时，不跨日借用电量；任何不完整日直接报错，不偷偷删小时。

离线基准移除预测触发门槛和软储备规则，保留所有共同硬物理约束。它是比冻结控制器更宽的可行集。若控制器本身可行且达到该更宽集合的下界，峰值最优结论也对其更窄集合成立；若控制器未达到下界，差距包含信息与规则的影响，不能全部归因于求解失败。

## 3. 第一层证明：放电功率下界和可行达到

对任何可行轨迹，c_t >= 0 且 d_t <= P_d，因此 L_t+c_t-d_t >= L_t-P_d。取最大值得到：

```text
z >= max_t L_t - P_d
```

2021 年下界为 70,449.90 - 1,250 = 69,199.90 MW；旧测试下界为 69,256 - 1,250 = 68,006 MW。构造满足所有 SOC、功率、日末等式和互斥约束、且每小时控制负荷不超过此下界的轨迹，即可证明该下界就是全局最优值。这是全局下界与可行上界重合的证明，与找到局部驻点无关。

2021 年现有新动态达到下界，旧测试现有新动态没有达到。两组新增离线调度均达到下界。

## 4. 第二层证明：最优峰值下最低吞吐

固定峰值上限 z* 后，每小时放电必有 d_t >= max(0,L_t-z*)。令 D_min = sum max(0,L_t-z*)。日末恢复和能量守恒给出 eta*C - D/eta = 0，即 C = D/eta²。于是：

```text
T = C + D = D*(1 + 1/eta²)
T >= D_min*(1 + 1/eta²)
```

精确有理数调度只在 L_t > z* 时放电 d_t = L_t-z*，其余小时在峰值和功率允许范围内补电，逐小时核验全部约束。如果该候选轨迹可行并恢复日末 SOC，就达到上述下界，从而证明第二阶段也全局最优。

这一贪心构造只是证书候选，并非所有数据都能成功的通用算法。若峰值出现在当日最后一小时，可能根本来不及补电；程序会拒绝出具证书。即使贪心失败，也不能推出下界不可达，须另行求解。

本次两个实例均成功，精确证书各只有 8 个非零动作，其他小时为零。原始十进制负荷按 CSV 字符串读取，eta 按 23/25 表示，全部运算使用 Python Fraction。JSON 中保存有理数峰值、吞吐下界、稀疏动作及模型，独立验证器逐小时重建能量轨迹，不调用求解器和贪心构造，不使用容差。CSV 本身部分数字带浮点序列化尾数；证书严格针对这些给定十进制值，而非未观测的真实电网连续信号。

## 5. 第三层证明：LP 强对偶与独立验证

并行证据路径将每天建成峰值 epigraph 线性规划，使用 HiGHS 求解并保存全部原变量和对偶变量。独立验证器从负荷、模型重新建立矩阵，检查原可行性、对偶符号、驻点方程、互补松弛和原始-对偶目标差，不以求解器 success 标志作为证明。

采用 SciPy 边际值符号：不等式 A*x <= b 的边际值 y <= 0，下界边际值 lo >= 0，上界边际值 hi <= 0，等式 v 无符号限制。要求：

```text
f - A.T*y - Aeq.T*v - lo - hi = 0
dual = b.T*y + beq.T*v + lower.T*lo + upper.T*hi
primal = f.T*x
```

无穷边界项排除且其乘子必须为零。可行的对偶值是最小化问题下界，原可行值是上界；重合给出全局最优。浮点路径允许原可行性 1e-5、对偶符号和驻点 1e-8、互补及目标差 1e-4，各小时物理轨迹另行检查。它提供明确容差的数值证书；精确有理数证书另提供零容差的下界达到证明。

日末能量等式使日期之间没有状态耦合。若每天最优峰值为 z_d*，全年最优峰值就是 max_d z_d*：任意全年轨迹不能低于每一天最优值，拼接各日最优轨迹又能达到最大日最优值。第二阶段所有天共享这个全年上限，而不是强迫每一天达到各自最低峰值；否则会无谓增加吞吐。各日最小吞吐之和即全年最小吞吐。

本次共求解 782 天、每一天两阶段，合计 1,564 个 LP 子问题，并保存和重新核验各自的原始-对偶证书。

## 6. 为什么无需充放电模式整数变量

一般电价或网络模型中的互斥约束可能需要 MILP。本模型仅限制净负荷上界，且目标是降低峰值及吞吐，所以能证明 LP 松弛精确。

若某小时 c,d 同时为正，记 SOC 增量 q = eta*c-d/eta。q >= 0 时取 c' = c-d/eta²、d'=0；q < 0 时取 c'=0、d'=d-eta²*c。变换后充放电均非负、不超过原动作，SOC 增量相同，净负荷不增加，吞吐减少。每小时独立变换保持整条 SOC 和日末等式。因此每个 LP 可行解都能转换为物理可行解，峰值和吞吐不增加；结合松弛下界，得到最优值相同。

代码实际执行该变换并重新审计物理轨迹。若加入负电价、充电补贴、负荷下界、爬坡、备用义务或复杂网络约束，变换可能破坏目标或约束，此证明立即失效，届时须使用明确互斥的 MILP 或其他有效松弛。本结论不可移植到原预测门槛的任意其他目标。

## 7. 数学方法选用与停止条件

| 方法 | 可以证明什么 | 本次处理 |
|---|---|---|
| 功率解析下界 + 可行达到 | 固定实例峰值全局最优 | 已完成，精确证书 |
| 能量守恒 + 必需放电下界 | 固定最优峰值下吞吐全局最优 | 已完成，精确证书 |
| LP 弱/强对偶、KKT | 线性规划全局最优与数值差距 | 已完成，独立验证原始-对偶见证 |
| 松弛精确性 + 构造变换 | 非同时动作物理模型与 LP 最优值相同 | 已证明并逐小时核验 |
| 分解与严格分层目标 | 全年峰值/吞吐组合问题 | 已完成，非加权近似 |
| MILP 分支定界 | 有模式、启停等离散约束的全局差距 | 当前证明已避免整数求解；有新增约束再采用 |
| 凸 CVaR 模型 | 一个明确定义的尾部均值目标 | 尚未实现，不得与 P95 互换 |
| 鲁棒/随机/分布鲁棒优化 | 给定不确定集合/分布内的最坏值或期望值 | 无真实未来集合或分布，暂不作保证 |
| 非凸全局方法、SOS/区间定界 | 适用的非凸模型及松弛差距 | 当前有限模型无需这些方法；不为增加术语而套用 |

在已证明的有限实例上继续降低峰值不可能；修改容量、功率、效率、日末约束或数据后已是新问题，须重新证明。最低吞吐离线问题也已闭合。在线策略在旧测试期尚有 604.15 MW 峰值差距，2021 年吞吐也远非离线最小，不能将这两项称为已解决的在线全局最优。

## 8. 为什么不能保证任意未来在线最优

离线最优知道未来，在线策略只知道截至当前的信息和预测。存在信息不可辨识的反例：取两小时、无损储能、初始与末尾能量 0、容量及功率 10，首小时负荷都为 10；后续负荷可以是 0 或 30。前一未来中离线选择不充电，最优峰值 10；后一未来中离线首小时充 10、次小时放 10，最优峰值 20。首小时任何在线动作必须相同：不充电会错失后一未来的最优，充正电会破坏前一未来的最优。没有额外信息，无法同时对两种未来达到离线最优。

该例用于说明普遍信息障碍，使用独立说明参数，不冒充项目默认参数的实证。即使滚动六小时 LP 每次被精确求解，也只是给定当时预测、状态和窗口目标的最优，不能推出全年真实负荷目标最优。

更换 P95、每日峰值、吞吐、成本、寿命、备用约束等目标会产生不同最优解。“所有指标、年份和场景同时最佳”不是已定义或可证明的单目标问题。后续在线策略开发应在新的训练/验证时段内选择明确主目标和副目标，冻结后用新的未使用时段复核；2021 年现在已知，不可再用于调参后继续宣称该修改独立验证。

```powershell
python scripts/certify_optimality.py

```

生成会写入新的 `outputs/optimality/`，不会修改冻结输入。`certificates.json` 保存输入和离线轨迹 SHA-256、解析证书、精确有理数证书、全部每日 LP 见证及两阶段结果。`independent_2021_oracle.csv` 和 `exploratory_test_oracle.csv` 为可回放的离线浮点轨迹。`--verify-only` 从既有文件独立重建核验，不调用优化器；冻结哈希仍由原独立验证预检核查。

测试包含手工可解实例、效率损耗、不能消耗初始电量降低常负荷、全年与每天峰值目标差异、最后一小时无法补电、不完整日期、被篡改对偶和精确动作拒绝案例。
