# 风险感知储能协同调控

## 目标

GridPulse 的升级模块不把预测、告警和储能看作互不关联的三个步骤。它使用直接 1--6 小时净负荷预测及其验证期校准区间，在每个小时重新决定储能的下一步动作和应保留的 SOC。目标是：在不确定的峰值窗口中，降低高分位净负荷，同时避免为了单一峰值而耗尽储能。

这是公开历史数据上的理论回测，不能替代实际储能 EMS、保护逻辑、市场交易或调度授权。

## 信息边界

对目标时刻 `t+h`，第 `h` 个直接模型只使用 `t` 时刻及更早的负荷、光伏、风电观测和已知日历特征，`h = 1, ..., 6`。每个模型只用验证期残差的 90% 分位数校准对称经验预测区间。当前版本没有使用未来天气或未来新能源功率，因此不把它称为日前 24 小时预测。

## 动态储备

令 `U_h` 为第 `h` 小时预测上界，`P_h` 为点预测，`T` 为验证期冻结的峰值阈值。对每个滚动窗口计算：

```text
severity    = clip((max(U_h) - T) / (0.10 * T), 0, 1)
uncertainty = clip(max(U_h - P_h) / (0.10 * T), 0, 1)
reserve_fraction = clip(0.15 + 0.20 * severity + 0.15 * uncertainty, 0, 0.60)
reserve_target = capacity * reserve_fraction
```

规则设计使预测上界或区间宽度增大时储备不减，但原版各时距半宽固定，窗口最大半宽 8,416.77 MW 大于尺度 5,540.63 MW，不确定性项始终饱和为 1。因此原版时间变化主要来自 severity，不能宣称已经隔离出时变不确定性的收益。动态储备不是电网安全标准。

## 滚动优化模型

在每个决策时刻，对未来 6 小时解一个线性规划，仅执行第一小时动作，再随着新预测滚动重算。

**决策变量：** 每小时充电功率 `c_h`、放电功率 `d_h`、窗口峰值辅助变量 `z`。

**目标：**

```text
minimize z + 0.001 * sum(c_h + d_h)
```

其中 `z` 表示预测上界减去储能放电、加上储能充电后的窗口最大净负荷。原版使用 `z + 0.001 * sum(charge + discharge)` 加权目标；该惩罚倾向减少循环，但数学上可能牺牲少量峰值改善，并不保证只在等价峰值方案间打破平局，也不等于严格两阶段优化。冻结代码和历史结果保留，新版控制器另行验证。

**约束：**

```text
U_h + c_h - d_h <= z
SOC_h = SOC_(h-1) + eta * c_h - d_h / eta
reserve_floor <= SOC_h <= capacity
0 <= c_h <= charge_limit
0 <= d_h <= discharge_limit
```

其中：

- `eta = 0.92`；
- 规划内每小时充电只在该小时预测下界低于验证期 25% 低负荷阈值时允许；只执行第一小时动作；
- 放电只在相应预测上界达到验证期峰值阈值时允许；
- `reserve_floor = min(reserve_target, current_SOC)`，是可低于目标的软下限；逐小时报告未达目标的次数，不能将其视为满足硬性备用义务；
- 放电上限取额定放电功率与容量/24 小时的较小值，充电上限单独取额定充电功率。

当前模型不强制期末 SOC 等于初始 SOC。策略可能消耗不同数量的初始能量，必须结合初末 SOC、吞吐和缺口解读 P95，不能据此推断稳态收益。

## 对照设计

| 策略 | 预测输入 | SOC 规则 | 目的 |
|---|---|---|---|
| 遗留一步规则 | 一步点预测 | 固定保留 30% 容量，极端时释放 | 仅记录原型演进 |
| 同信息固定储备基线 | 直接 1--6 小时点预测与区间 | 固定 30% 储备 | 核心公平消融 |
| 风险感知优化 | 直接 1--6 小时点预测与区间 | 随预测上界与区间宽度动态保留 | 比较风险储备、P95 和循环权衡 |

当前版本保留一个遗留的一步预测固定规则，用于说明原型演进；它不再用于证明动态储备的优势。核心消融使用相同的直接 1--6 小时预测、滚动线性规划目标、容量、功率、效率、充电阈值和测试窗口，仅把 SOC 储备规则设为固定 30% 或动态储备。报告同时展示受控 P95、全期最大削峰、SOC 最低值、吞吐量和等效全循环，避免只挑选有利指标。

## 当前冻结测试证据

| 容量 | 同信息固定 30% 储备 P95 (MW) | 风险感知 P95 (MW) | P95 差值 (MW) | 固定/风险感知等效全循环 |
|---|---:|---:|---:|---:|
| 10 GWh | 54,200.8 | 54,188.3 | -12.5 | 0.78 / 0.84 |
| 20 GWh | 54,185.0 | 54,150.2 | -34.9 | 0.81 / 0.86 |
| 30 GWh | 54,177.4 | 54,077.7 | -99.7 | 0.84 / 0.89 |

风险感知策略在三个容量情景均降低 P95，同时保持略高的最低 SOC；代价是理论吞吐与等效全循环略高。两种策略都没有降低测试期的单一最高净负荷，因此全期最大削峰同为 0 MW。该结果支持“动态储备改善高分位压力”的有限结论，不支持实际电池寿命、成本或可靠性收益结论。

## 补充机制实验

`scripts/strengthen_evidence.py` 使用验证期按目标小时校准的区间，并以验证期最大半宽的 1.10 倍（11,286.50 MW）作为独立不确定性尺度，使该分量随窗口变化。点预测保持不变，固定储备、仅严重度、仅区间宽度与组合储备使用相同 10,030 个规划时点和约束；另外单独比较放电上限减半和充电上限加倍。

| 30 GWh 策略 | P95 (MW) | 吞吐 (MWh) | 期末 SOC (MWh) | 目标未达小时 |
|---|---:|---:|---:|---:|
| 固定 30% | 54,185.00 | 43,319.00 | 9,000.00 | 0 |
| 仅严重度 | 54,135.68 | 53,865.81 | 4,545.92 | 1,644 |
| 仅区间宽度 | 54,177.35 | 51,064.76 | 7,239.29 | 3,452 |
| 组合 | 54,119.15 | 52,967.40 | 7,697.08 | 2,445 |
| 组合，放电 625 MW | 54,150.15 | 31,156.34 | 7,803.19 | 2,374 |
| 组合，充电 2,500 MW | 54,119.15 | 54,605.95 | 7,697.08 | 2,487 |

初始 SOC 均为 15,000 MWh。组合相对固定储备的 P95 下降 65.85 MW，吞吐增加 9,648.40 MWh，期末能量降低。充电功率加倍未进一步改善 P95，说明更大功率不必然改善当前目标。各策略全期最大削峰仍为 0 MW。该分析在原结果已知后提出，属于探索性补充，不能作为独立未触碰测试集上的策略选择证明，也不替代原版冻结证据。

## 原版每日能量恢复与共同硬下限

`scripts/run_balanced_storage.py` 进一步检查初始能量和补电成本。使用相同的直接预测与验证期按小时校准区间，仅保留 417 个完整 UTC 日（10,008 小时），排除首尾两个不完整日。每个日实验初始 SOC 为 15,000 MWh，容量 30,000 MWh，充放电上限均为 1,250 MW，单向效率 0.92。固定和动态策略共享硬下限 4,500 MWh；高于该下限的储备目标仍为软目标。

每日恢复模式另设 SOC 上限 15,000 MWh，并允许任意小时补电。若当前小时距日末尚余 `r` 个小时，则下一步 SOC 至少为 `15,000 - (r-1) * 1,250 * 0.92`，确保额定充电功率下仍可恢复；日末 SOC 精确回到 15,000 MWh。该可达性假设需要全天允许额定补电，不代表真实网络约束下可行。未来实际净负荷不参与求解，日历截止时间和发布时已知预测是规划输入。补电增加的负荷和转换损耗均计入结果。

| 独立日实验 | P95 (MW) | 最高净负荷 (MW) | 吞吐 (MWh) | 净消耗初始能量 (MWh) |
|---|---:|---:|---:|---:|
| 固定，未恢复 | 53,905.90 | 69,122.05 | 216,309.70 | 235,119.24 |
| 动态，未恢复 | 53,900.95 | 69,256.00 | 168,688.69 | 180,487.45 |
| 固定，每日恢复 | 54,045.74 | 69,122.05 | 410,854.95 | 0.00 |
| 动态，每日恢复 | 54,030.65 | 69,256.00 | 350,858.30 | 0.00 |

每日恢复下，动态策略相对固定 P95 下降 15.09 MW（约 0.028%），吞吐减少 59,996.65 MWh，转换损耗分别为 29,187.52 与 34,178.57 MWh。共同硬下限违规为 0，最大日末误差为 0，小时能量守恒最大误差低于 1e-9 MWh。但动态策略最高峰值仍未降低，固定策略降低 133.95 MW；动态软目标未达 17 小时。因此动态策略只在部分指标上更好。

未恢复模式每天重置初始能量，仅为实验对照，不是可持续运行。恢复与未恢复模式同时改变了补电权限和 SOC 上限，不能把两模式之间的全部差异归因于日末 SOC 等式。每日结果也不能直接与原版连续全期实验比较。该实验在原测试结果已知后提出，属于探索性证据，仍缺少独立新数据、网络、价格和退化验证。

## 极端峰值响应改进

后续复核将点预测定位峰值与极端预测触发的软储备释放分开消融。新动态组合在相同每日恢复条件下将测试期全期最高峰从 69,256 MW 降到 68,610.15 MW，削减 645.85 MW；P95 降到 53,860.55 MW。但吞吐从 350,858.30 增到 651,031.03 MWh，损耗从 29,187.52 增到 54,158.56 MWh。新固定组合最高峰相同，P95 更低，吞吐更高。方法、六组验证/测试对照及探索性边界见 `docs/peak-response.md`，不能以本补充替换原版证据或宣称全面优势。

## 复现命令

2021 年后续时间留出使用冻结模型与控制参数，六组同评 365 天。新动态相对原动态最高点降低 1,250 MW，平均日最高点降低 237.39 MW；全年 P95 升高 72.97 MW，吞吐和损耗更高，Q3 极值变差。见 `docs/independent-validation.md`，仅支持限定的历史时间泛化与指标取舍结论。

```powershell
python scripts/train_multihorizon.py
python scripts/run_storage_scenario.py
python scripts/strengthen_evidence.py
python scripts/run_balanced_storage.py
python scripts/run_peak_response.py
```

输出：

- `outputs/models/multihorizon_metrics.json`：直接 1--6 小时预测和区间指标；
- `outputs/models/direct_horizon_test_predictions.csv`：按目标时刻和发布时刻对齐的预测；
- `outputs/scenarios/storage_*_fixed_timeseries.csv`：固定储备基线轨迹；
- `outputs/scenarios/storage_*_risk_aware_timeseries.csv`：动态储备滚动优化轨迹；
- `outputs/scenarios/storage_scenario_metrics.json`：对照汇总。
- `outputs/scenarios/reserve_ablation_metrics.json`：补充分量、功率、区间覆盖率与初末 SOC 证据。
- `outputs/scenarios/daily_energy_balance_metrics.json` 与 `daily_*_timeseries.csv`：四组每日初末能量、补电与损耗的可审计证据。
- `outputs/scenarios/peak_response_metrics.json` 与 `peak_*_timeseries.csv`：最高峰响应、机制消融和补电循环代价。
