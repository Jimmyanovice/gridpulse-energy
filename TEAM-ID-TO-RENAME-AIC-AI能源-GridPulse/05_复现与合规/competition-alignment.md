# 赛题对齐与工程验收矩阵

## 1. 适用范围

本文依据赛事官网发布的《AIC·AI+能源竞赛规则及作品提交要求-科技创新组》及其技术报告参考大纲整理。官网附件是本项目的验收和材料编排依据。

## 2. 申报定位

**作品名称：** GridPulse：面向新能源波动的净负荷预测与风险感知储能规划

**拟申报方向：** 科技创新组，主方向为“（5）新能源消纳与并网智能调控”。

**关联方向：**

- “（4）电力消费侧能效分析与节能优化”：净负荷、峰值和储能削峰情景可作为辅助分析；
- “（9）电力应急响应与辅助决策智能化应用”：风险复核队列和规则化建议可作为辅助决策原型。

不将作品表述为真实调度系统、设备故障诊断系统或已经部署的节能产品。当前工程边界是：使用 OPSD 德国历史公开数据，验证一个可复现的新能源消纳决策支持原型。

## 5. 工程链路

后续时间留出证据：Energy-Charts.info 德国 2021 全年，先冻结协议再下载，原模型和阈值不调整。六组共享 365 日、8,760 小时。新动态最高点相对原动态低 1,250 MW，平均日最高点低 237.39 MW（7 天配对重采样 95% 区间 [184.73,293.93]），但全年 P95 高 72.97 MW、Q3 极值高 230.18 MW，吞吐多 592,789.18 MWh。完整方法、失败与限制见 `docs/independent-validation.md`，该证据不支持现场可靠性或收益承诺。

```text
OPSD 公开数据
  -> 下载与字段标准化
  -> 时间、数值、公式质量检查
  -> 净负荷与滞后特征
  -> 一步超前预测与经验区间
  -> 峰值/光伏骤降/持续偏差候选风险
  -> 人工复核队列与约束说明
  -> 理论储能削峰情景
  -> Streamlit 演示、技术报告、PPT
```

## 6. 还不能由公开数据证明的要求

新增数学最优性、循环代价和运行边界证据见 `docs/global-optimality.md` 与 `docs/controller-development.md`。2021 年最高点达到固定物理模型下界，候选两阶段控制器未通过原验证期准入，保留原策略。已完成新能源高占比时段充电和净负荷爬坡评价，但结果不支持“已减少弃风弃光”的主张；实际新能源可用出力与弃电数据仍缺失。

这些项目不是代码缺失，而是需要新增合法数据、设备接口或运行授权：

1. 真实故障或运行事件标签，以及真实故障检测准确率；
2. 实时量测、日前天气预测或新能源功率预测，以支持直接 24 小时预测；
3. 电网拓扑、线路容量、储能额定参数、SOC 和保护约束；
4. 电价、退化、备用义务、调度授权和现场安全审批；
5. 实际部署时延、稳定性、节省金额、碳减排和可靠性收益；
在取得上述输入前，仓库只应宣称“可运行的历史回测与理论情景原型”。
