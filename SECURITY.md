# Security and Safety Policy

GridPulse is a research prototype and must not be used as an autonomous operational control system.

## Reporting a Concern

Before a public contact channel is configured, do not disclose sensitive details in a public issue. Open a minimal issue that requests a private contact path, or contact the repository maintainer through the GitHub profile associated with the repository.

## Scope of Concerns

- Data leakage or invalid time-series evaluation.
- Incorrect attribution, licensing, or exposure of restricted data.
- Unsafe wording that could cause the prototype to be interpreted as a production control or fault-diagnosis system.
- Accidental commitment of credentials, local paths, personal data, or large private artifacts.

## Response Target

Reports should receive an acknowledgement within 14 days once a public repository and maintainer contact channel exist. No deployment or safety certification is implied by this policy.
